### 💻 Portfólio & Currículo Pessoal

Este repositório contém o código-fonte do meu **Portfólio e Currículo Pessoal**, desenvolvido como parte das atividades práticas do curso Técnico em Desenvolvimento de Sistemas. O objetivo é apresentar minhas habilidades, projetos e canais de contato em uma página web estruturada de forma limpa e semântica.

### 🛠 Tecnologias Utilizadas

O projeto foi construído utilizando conceitos fundamentais de desenvolvimento web focado em estrutura e semântica: 

* **HTML5:** Estruturação semântica de textos, tabelas, imagens e formulários.
* **CSS3:** Noções básicas aplicadas à organização visual do layout.

### 📂 Estrutura da Página

A página foi planejada para oferecer uma navegação rápida e direta através de seções interligadas por links internos: 

1. **Sobre Mim:** Breve introdução sobre minha trajetória acadêmica e tecnologias de foco.
2. **Minhas Habilidades:** Listagem das principais tecnologias que domino ou estou praticando.
3. **Meus Projetos:** Uma tabela detalhada contendo o nome do projeto, tecnologias envolvidas, status atual e o link direto para o repositório no GitHub.
4. **Entre em Contato:** Um formulário funcional para captação de mensagens de visitantes, integrado a links diretos para e-mail e telefone.

### 🚀 Como Executar o Projeto

1. Faça o clone ou baixe este repositório.
2. Navegue até a pasta do projeto.
3. Abra o arquivo index.html em qualquer navegador web de sua preferência.
